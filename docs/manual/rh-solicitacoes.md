# Solicitações de ajuste

## Para que serve
Recebe os pedidos dos funcionários para incluir uma marcação esquecida ou desconsiderar uma marcação indevida.

## Passo a passo
1. Use as abas **Pendentes**, **Aprovadas**, **Recusadas** e **Canceladas**.
2. Clique em **Espelho** para conferir o dia antes de decidir.
3. Clique em **Aprovar** (observação opcional) ou **Recusar** (informe o motivo) e confirme.

## Dúvidas comuns
- **O funcionário vê minha resposta?** Sim, na área dele.
- **O Gestor pode aprovar?** Não. Apenas RH e Administrador.
- **O que é "Cancelada"?** O funcionário desistiu do pedido enquanto estava pendente.

## Regras importantes
- A aprovação gera um tratamento auditado; a marcação original é preservada.
